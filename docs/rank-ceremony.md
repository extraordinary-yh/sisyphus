# 段位与逐星演出

大厅中央展示当前段位徽章、金属星槽和累计段位星。每日结算采用全屏演出；进入页面并加载成功后，自动回放洛杉矶时区昨天已结算的记录。昨天缺少结算时不自动播放其他日期，不会自动结算或更改任何记录。刷新页面会再次回放；同一次加载中的重新读取不会重复弹出。

每颗星经过蓄势、飞入星槽、撞击与余光，再进入下一颗。加满最后一个星槽后才切换新段位；小段、大段和王者称号变化均有晋级或回落阶段。扣星逐颗演出，废铁底线仍显示扣星原因，但不制造负分或从空星槽抽走星星。结算最后显示原始获得、原始扣除与实际段位变化。

可以暂停、继续、切换 1× / 2× 或直接查看结果。切到后台不会跳过一串未观看的星星。减少动态效果设置会关闭飞行、碎片、震动与徽章位移动画，仍按次序展示每颗加减星。

## 音效

星星落槽采用原创 Web Audio 合成：短促高频敲击、非整数倍金属共振和轻微低频主体。升星尾音最长约 0.9 秒，晋级、掉段和结算使用独立提示音。没有下载或复制游戏音频。暂停、关闭和静音会停止当前演出声音。

默认请求开启音效，并尊重已保存的静音选择。浏览器可能禁止首次自动发声，届时点击“开启打铁音效”或在页面上交互即可解锁；动画照常自动播放。参考 [Chrome Web Audio 自动播放说明](https://developer.chrome.com/blog/web-audio-autoplay?hl=en)。

视觉编排按需求中的“天上落星、镶嵌星槽、金属撞击、段位变化”制作。研究时找到 [王者荣耀段位晋级动画合集](https://www.bilibili.com/video/BV1Vf4y1y7uq/)，但该播放器未能播放，因此并非逐帧复刻；星星、动效和音效均为本项目实现。

## 开发验证

开发服务器下打开 `/ceremony-preview`，可播放小段晋级、大段晋级/掉段、王者称号变化、底分保护及零星账单。也可定格落星、晋级和掉段，检查星槽落点。全部使用虚构结果，不读取或写入数据库，生产环境返回未找到页面。

“检验合成音效”使用 OfflineAudioContext 渲染各个音效并显示峰值及 RMS，可检查静音或削波错误；这些数字不替代主观听感评估。相关单元测试位于 `tests/ceremony.test.mjs`。
